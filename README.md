# ASCII Run

A browser-based ASCII platformer. Plain HTML, CSS and JavaScript — no build step, no dependencies.

## Up & go

```bash
git clone https://github.com/efesezenk/ascii-run-3.git
cd ascii-run-3
python3 -m http.server 8000
```

Then open http://localhost:8000

Prefer Node?

```bash
npx serve .
```

## Tests

```bash
node tests/smoke.js
```
